# Бот для мониторинга IT-вакансий

Я ищу первую работу в IT и каждый день заходил на одни и те же сайты и в одни и те же телеграм-каналы. Надоело, поэтому написал бота. Раз в полчаса он обходит источники из моей Excel-таблицы и присылает в Telegram только новые вакансии, которые мне подходят.

Ищет два направления: Python/backend и системная/IT-аналитика.

## Что он делает

Список источников бот берёт из листа «IT-каналы» в Excel: там hh.ru, Habr Career и публичные Telegram-каналы. Добавил строку в таблицу, и бот начал её проверять.

Вакансии отбираются по названию (у постов в Telegram по первым 200 символам). Старшие позиции вроде senior и lead отсекаются, если нет слов junior или «стажёр». Чужие стеки (Java, PHP и так далее) отсекаются, если в названии нет Python. Дальше бот проверяет, что вакансия не протухла: посты старше двух недель и посты с пометкой «вакансия закрыта» он пропускает. Если вакансия с hh или Habr закрылась уже после того, как я получил уведомление, придёт отдельное сообщение.

Одна и та же вакансия может висеть на hh, на Habr и в трёх каналах сразу, но придёт она один раз. Если какой-то источник перестал отвечать, бот напишет мне об этом.

## Как запустить

Нужен Python 3.9 или новее.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Дальше нужен бот в Telegram. Пишем @BotFather, команда `/newbot`, токен вставляем в `.env`. Потом открываем своего бота, нажимаем Start и запускаем:

```
python main.py --get-chat-id
```

Число из ответа вставляем в `.env` как `TELEGRAM_CHAT_ID`. Проверка связи:

```
python main.py --test-notify
```

Если сообщение пришло, запускаем сам бот: `python main.py`. Для проверки без отправки в Telegram есть `python main.py --dry-run`, он всё печатает в консоль и ничего не сохраняет. `python main.py --list-sources` показывает, какие источники бот взял из Excel. `python main.py --once` делает одну проверку и выходит, это удобно для планировщика заданий.

При первом запуске бот пришлёт одним списком всё свежее, что нашёл за последние две недели, дальше только новое.

## Как настроить

Всё в `config.yaml`. Там интервал проверки, нужные приоритеты источников и правила отбора вакансий. Правила написаны регулярными выражениями, рядом есть комментарии. Если в уведомлениях много лишнего или, наоборот, что-то пропадает, править нужно блок `tracks`.
Добавить Excel файл (.xlsx) в папку где находится файл main.py

## Что не работает или работает плохо

С hh.ru сложнее всего. С апреля 2026 публичный API hh отдаёт 403 без токена приложения, а такие токены выдают в основном работодателям. Поэтому бот читает обычные страницы поиска. Сайт может включить защиту от ботов или поменять вёрстку, тогда бот напишет, что источник не отвечает.

Ещё не подключены:
- боты из таблицы (getmatch и parser bot), их нельзя читать как каналы;
- Freelansim, там фриланс-заказы, а не вакансии;
- карьерные сайты компаний из листа «Компании-мишени».

Закрытые каналы и каналы без веб-просмотра бот тоже не прочитает.

## Из чего состоит

- `main.py` запускает проверки и отправляет уведомления
- `sources.py` умеет читать hh, Habr и Telegram и грузит список из Excel
- `filters.py` отбирает вакансии по ключевым словам
- `storage.py` хранит в SQLite, что я уже видел
